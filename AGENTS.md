# Trance — agent instructions

The rules live in **[`CLAUDE.md`](CLAUDE.md)**. Read that file, then read
**[`TRANCE.md`](TRANCE.md)** in full before touching anything.

This file exists because some agents look for `AGENTS.md` and some look for `CLAUDE.md`.
It is a pointer, not a second copy: two copies of the same rules drift, and the copy an
agent happens to load then decides which rules it follows.
