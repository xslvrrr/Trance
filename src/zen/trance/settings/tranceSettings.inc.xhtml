If a pref is # not on this page, it should not exist (TRANCE.md §6.6). # # ── The shape of this file ───────────────────────────────────────────────── # # Every setting is one row, and every row is the same three pieces: a name, a # sentence saying what it does, and its control. That is the whole convention, # and it is worth stating because the previous version did not have one — a # checkbox carried its explanation in its own `label`, a slider carried none, and # a paragraph at the top of each group carried the rest. Reading the pane meant # reading prose to find out which line was a setting. # # `.trance-row-child` marks a row that only means something while the row above # it is on. It is indentation with a rule behind it, not decoration. # # Labels are literal text rather than `data-l10n-id`. Zen's own preference # strings live in its downloaded language packs, not in this tree, so there is # no Trance .ftl to add ids to yet. Localisation is a Phase 12 concern; shipping # untranslated-but-present beats shipping an empty pane. # # Refs: TRANCE.md §6.6, §13 Phase 2, §13 Phase 3
